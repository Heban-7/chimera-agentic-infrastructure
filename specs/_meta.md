## Vision

Project Chimera transitions AI from automated content scheduling to the creation
of **Autonomous Influencer Agents** — persistent, goal-directed digital entities
capable of perception, reasoning, creative expression, and economic agency. Managed
by a single human Super-Orchestrator via Fractal Orchestration, powered by the
FastRender Swarm pattern and the Model Context Protocol.

## Architectural Pillars

1. **FastRender Swarm (Planner → Worker → Judge)** — Hierarchical task execution
2. **Model Context Protocol (MCP)** — Universal external connectivity
3. **Agentic Commerce (Coinbase AgentKit)** — Non-custodial on-chain transactions
4. **Addis Ababa Resilience** — Async-first, Redis-backed durability

## Constraints

- **SDD:** No implementation without ratified specs.
- **MCP-Only:** No direct external API calls in core logic.
- **Financial Safety:** All transactions pass through the CFO Judge.
- **Addis Context:** Async-first, generous timeouts, exponential backoff.
- **Ethical:** AI disclosure on all published content. Honesty directive enforced.
